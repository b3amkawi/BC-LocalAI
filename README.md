# BC-LocalAI

ASP.NET Core MVC web application targeting .NET 10.

## Requirements

- .NET 10 SDK

## Run locally

```powershell
dotnet run --project .\BC-LocalAI\BC-LocalAI.csproj --launch-profile http
```

Open <http://localhost:5290> in a browser.

## Build

```powershell
dotnet build .\BC-LocalAI.slnx
```
