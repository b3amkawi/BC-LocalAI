## 3. ข้อจำกัด
- ทดสอบ "ห้องสำหรับคำตอบยาว" ไม่ได้ผล: คำตอบที่ขอให้ทวนรหัสเดิม 60 บรรทัดทำให้รหัสอยู่ในคำตอบเอง จึงตอบถูกทุกบรรทัดแม้ prompt 3,519 + คำตอบ 1,020 เกิน 4,096 (59/60 บรรทัดในหนึ่งการรันที่ 3,233) ไม่ใช้เป็นหลักฐานว่าปลอดภัย นโยบายจึงใช้เพดานอนุรักษ์ ctx − 1024 − overhead
- ตัวอย่างเป็นข้อความสังเคราะห์ (ประโยคซ้ำ) ไม่ใช่บทสนทนาจริง; multi-turn ทดสอบ 2 ตาประวัติ + 1 คำถาม
- วัดบนเครื่องนี้ (RTX 4050) เท่านั้น; 8192 ไม่ได้วัดร่วมกับ NUM_PARALLEL=2; log ของ Ollama (บรรทัด `truncating input prompt`) ไม่ได้เก็บ ใช้ `prompt_eval_count` แทน
